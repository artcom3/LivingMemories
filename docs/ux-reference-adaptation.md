# Functional UX reference adaptation

The original functional review used `ux-reference-not-use-ui` at commit `00e2944`. It examined routes, handlers, form state, and models. Its components, styles, assets, and visual identity were not adopted. The [Spanish adaptation record](history/es/docs/ux-reference-adaptation.md) preserves the complete comparison and validation scope.

## Maintained boundaries

Private families, adult accounts, current membership checks, and independent narrator profiles remain the foundation. Albums group memories without duplicating originals. Context belongs to each material and remains distinct from confirmed facts. Preparations reference selected sources and can be saved and resumed.

The adapted capture flow supports memories, narrator attribution, text/photos/recordings, optional context, albums, filtering, and withdrawal/recovery. Later work adds video inputs, staged story/music generation, translation, and source-origin inspection; see the [content guide](content-generation.md). The earlier adaptation report's exclusions describe its delivery milestone.

The repository's own visual system takes precedence over the reference. Simulated generation, external demonstration media, a global demo user, and automatic completion messages are not evidence of implemented provider integration.

The reference paths named in the archived comparison belong to commit `00e2944`; consult that revision when studying those routes. Current implementation paths and behavior may differ.
