The snapshot was taken during the language review on 2026-10-17, including existing working-tree edits. Original files are kept byte for byte under `es/`, with their former repository paths preserved beneath that directory.

Start with the [current English documentation](../README.md) for setup and maintained guidance. These records describe decisions, proposals, and tests at different points in development. A historical pending item may now have an implementation; a historical successful local test does not establish a current deployment.
